プライバシーポリシー

このアプリは、誰消え雑学の運営者が自分のYouTubeチャンネルに動画を投稿するためだけに使う個人用ツールです。運営者以外の利用は想定していません。

取得する情報

Google OAuthを通じて、YouTubeチャンネルへの動画アップロード権限と、チャンネル情報の読み取り権限を取得します。

利用目的

取得した権限は、運営者自身のチャンネルへの動画投稿と、投稿先チャンネルの確認にのみ使います。

保存と共有

認証情報は運営者のPC上にのみ保存し、第三者に提供・販売することはありません。

このアプリによるGoogle APIから取得した情報の利用は、限定的使用の要件を含むGoogle API サービスのユーザーデータに関するポリシーに従います。

YouTube API サービスについて

このアプリはYouTube API サービスを使用しています。YouTube 利用規約およびGoogle プライバシーポリシーもあわせてご確認ください。アクセス権はGoogleアカウントの権限設定からいつでも取り消せます。
